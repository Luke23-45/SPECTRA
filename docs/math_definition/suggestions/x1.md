


### Phase 1: Re-parameterizing the Bounds (Precision-Space instead of Log-Variance)

**The Problem:**
In the canonical definition, bounds are defined directly in the log-variance space as $s_i \in (a_i, b_i)$. Guessing raw log-variance scales is non-intuitive and prone to hyperparameter errors (e.g., bounds of $[-10, 10]$ mapping to a maximum precision weight of $22,026$). 

**The Mathematical Refinement:**
Define the bounds strictly in the intuitive **Precision Space ($\omega$)**. 
Let the desired minimum and maximum network weights be defined by the user as $\omega_{min}$ and $\omega_{max}$ (where $0 < \omega_{min} < \omega_{max}$).

Since the canonical map is $\omega_i = e^{-s_i}$, the required bounding interval $(a_i, b_i)$ in log-variance space is uniquely determined by reversing the mapping:
$$b_i = -\log(\omega_{min})$$
$$a_i = -\log(\omega_{max})$$

*Result:* By mapping $\omega_{min}$ and $\omega_{max}$ directly to $b_i$ and $a_i$, we guarantee the final precision weight applied to the network loss structurally satisfies $\omega_{min} < \omega_i(\theta_i) < \omega_{max}$. This natively prevents both precision collapse (task starvation) and gradient explosion without altering the canonical proofs.

### Phase 2: The Surrogate Statistic ($m_i$) and Scale Invariance

**The Problem:**
In the canonical definition, the surrogate is $m_i = \ell_i(w)$. From Proposition 3, this yields the optimal target $\omega_i^\star = 1/\ell_i(w)$. If the absolute magnitudes of all tasks shrink to very small numbers (e.g., $0.001$), the unnormalized target explodes to $1000$ for all tasks, causing a global learning rate explosion. UW-SO avoids this via a Softmax, but Softmax creates a zero-sum game that tightly couples tasks and causes starvation.

**The Mathematical Refinement:**
We introduce a scale-invariant surrogate by normalizing against the mean task loss. Let $\bar{\ell}(w)$ be the mean loss across all $T$ tasks at the current step:
$$\bar{\ell}(w) = \frac{1}{T} \sum_{j=1}^{T} \ell_j(w)$$

Redefine the canonical surrogate state:
$$m_i = \frac{\ell_i(w)}{\bar{\ell}(w)}$$

*Result:* The optimal target mathematically shifts to $\omega_i^\star = \frac{\bar{\ell}(w)}{\ell_i(w)}$. 
If a task has exactly average difficulty ($\ell_i = \bar{\ell}$), its target weight is exactly $1.0$. The weights are now completely scale-invariant, preventing global learning rate explosions if absolute losses are small, while keeping the uncertainty coordinates ($\theta_i$) mathematically decoupled and independent.

### Phase 3: Analytical Tracking (AT) via Bounded Subspace Flow

**The Problem:**
Step 7 in the canonical definition uses a generic optimizer $\mathcal{U}_\theta$ (like Adam or SGD) to minimize $J_{unc}$. Gradient-based tracking introduces optimizer hyperparameters (learning rates, momentum) that can lag significantly behind the optimal stationary targets, causing B-PGS to react too slowly compared to instantaneous methods.

**The Mathematical Refinement:**
From Proposition 3, the exact stationary point for the surrogate is $s_i^\star = \log m_i$. 
We mathematically project this optimal target backward through the B-PGS chart directly into the unconstrained $\theta$-space.

Let $p_i^\star$ be the normalized target within the log-variance bounds:
$$p_i^\star = \frac{\log m_i - a_i}{b_i - a_i}$$

Clip strictly to the open interval constraints using a constant $0 < \varepsilon < 1/2$:
$$\tilde{p}_i^\star = \min(1-\varepsilon, \max(\varepsilon, p_i^\star))$$

The optimal analytical coordinate in $\theta$-space is the exact inverse-sigmoid:
$$\theta_i^\star = \log\left(\frac{\tilde{p}_i^\star}{1-\tilde{p}_i^\star}\right)$$

Replace the gradient descent optimizer $\mathcal{U}_\theta$ with an Exponential Moving Average (EMA) update strictly in $\theta$-space:
$$\theta_{t+1} = (1-\beta)\theta_t + \beta \theta_i^\star$$
*(where $\beta \in (0, 1]$ is the tracking momentum).*

*Result:* 
* If $\beta = 1.0$, B-PGS snaps instantly to the scale-invariant optimal target (while remaining strictly bounded by $\omega_{min}$ and $\omega_{max}$). 
* If $\beta < 1.0$, B-PGS acts as a structural low-pass filter, smoothly tracking the optimal analytical targets, filtering out mini-batch noise, and completely eliminating the computational overhead and instability of a secondary Adam/SGD optimizer.
